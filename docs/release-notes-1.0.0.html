LookBridge 1.0.0

The first LookBridge release brings CDL Auto Apply and Reference Still Auto Overlay together for DaVinci Resolve Studio on Mac.

  • One Resolve launcher for CDL matching and reference-still workflows.
  • A/B and Difference reference review, opacity, grab navigation, and PSNR comparison.
  • Universal Mac installer for Apple Silicon and Intel.
  • Manual update checking and optional automatic updates, with signed feed and installer verification.
  • Small, optional QuickBooks support links in the Resolve popup.

Requires macOS 12 or later and DaVinci Resolve Studio. Reference workflow developed for Resolve 21.0.4. The app is ad-hoc signed, not Apple-notarized.
