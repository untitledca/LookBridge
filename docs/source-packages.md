# Source packages

LookBridge 1.0.0 packages the two archives supplied for this task:

| Archive | SHA-256 |
| --- | --- |
| `resolve-cdl-auto-apply-universal.zip` | `203e20527671aa02ed8332f2f5461dfb948bf38e0c26cd5de957d8fa94a66dbb` |

The original matching, CDL application, reference placement, comparison, OCR, and PSNR implementations are preserved. Integration changes add a shared launcher, optional support/update links, private-module discovery, explicit CDL entry-point arguments, and installer-specific error wording. The tests were moved into a combined test tree with their import paths adjusted.

Original README files are retained in `docs/originals` as historical source documentation. Their installation statements describe the source packages, not the LookBridge installation state.
